---
title: Algebra lineal, matrices y sistemas
---

Un vector representa una lista ordenada, una matriz organiza datos o codifica una transformacion,
Un sistema lineal puede escribirse como A x = b,
La eliminacion de Gauss transforma filas para hallar soluciones, conserva el conjunto de soluciones si cada operacion es valida,

Un espacio vectorial contiene vectores que pueden sumarse y multiplicarse por escalares,
Un subespacio tambien cumple esas reglas,
La independencia lineal significa que ningun vector de la lista sobra,
Una base es un conjunto independiente que genera todo el espacio,

Comprueba dimensiones antes de multiplicar matrices,
Interpreta las operaciones geometricamente y separa solucion exacta de aproximada,
