---
title: Configuracion de git
---

En **git**, siempre se debe asociar un proyecto a una persona/empresa

Lo minimo para configurar **git** es un user y un email, para h~~a~~acer esta configuracion usamos los siguiente comandos

```bash
git config --global user.name "nombre"
git config --global user.email "correo@example.com"
```

El primer comando guarda el nombre y el segundo el correo

## **Git Init**

Para inicializar git en un directorio, lo que hacemos es que pondremos `git init`
