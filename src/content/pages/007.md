---
title: Configuracion de Git
---

En git, siempre se debe asociar un proyecto a una persona/empresa

Lo minimo para configurar git es un user y un email, para h~~a~~acer esta configuracion

Para dejar esos datos configurados en mi computadora uso este bloque de codigo

```bash
git config --global user.name "Mi nombre"
git config --global user.email "tu-correo@example.com"
```

El primer comando guarda mi nombre y el segundo mi correo
