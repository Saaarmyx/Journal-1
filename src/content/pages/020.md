Yo trato cada proposicion como una afirmacion verdadera o falsa, un predicado depende de una entrada,

El cuantificador para todo cubre cada caso, el cuantificador existe afirma que hay al menos un caso,

Yo agrupo elementos en conjuntos, uso relaciones para conectar pares y funciones para asignar una salida a cada entrada,

Una prueba directa parte de las hipotesis, una contradiccion supone lo opuesto, un contraejemplo basta para refutar una regla general,
