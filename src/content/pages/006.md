title: Trigonometria y periodicidad
---

Las funciones exponenciales describen cambios multiplicativos, las funciones logaritmicas responden cuantas veces debe multiplicarse una base para obtener un valor,
El circulo unitario conecta angulos con coordenadas, cos(t) es la coordenada horizontal y sin(t) la vertical,
Un radian mide un angulo como longitud de arco dividida por radio,

En un triangulo rectangulo, sin(t) = opuesto / hipotenusa, cos(t) = adyacente / hipotenusa, tan(t) = opuesto / adyacente,
Una identidad relaciona funciones para todo valor permitido, sin(t)^2 + cos(t)^2 = 1,
