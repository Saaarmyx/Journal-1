En MacOS casi siempre ya traes una version de Git instalada, pero si quieres instalarla o actualizarla

> Puedes ver si tienes Git, solo escribiendo `git` o `git -v` en la terminal

Debes ir a la pagina oficial y para:

- Windows: instalamos el .exe de toda la vida

- MacOS: `brew install git`

- Linux: Deṕende la distribucion

## Importante

Debemos saber Terminal o algun tipo de bash
