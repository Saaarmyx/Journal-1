title: Mi prueba por induccion
---

Para n = 1, ambos lados valen 1, esa es mi base,

Ahora supongo que la suma hasta n vale n(n + 1)/2,

Para llegar a n + 1 sumo n + 1 a ambos lados, obtengo n(n + 1)/2 + n + 1,

Factorizo n + 1, queda (n + 1)(n/2 + 1) = (n + 1)(n + 2)/2, esa es la formula para el paso siguiente,

Yo ya verifique base e induccion, por eso la afirmacion funciona para todos los enteros positivos,
