---
title: Metodos numericos, aproximar con cuidado
---

Los computadores guardan numeros con precision finita, algunos valores solo pueden aproximarse,
El error absoluto compara diferencia directa, el relativo compara esa diferencia con el tamano del valor,
El condicionamiento describe cuanto cambia la respuesta ante un pequeno cambio de entrada,
La estabilidad describe si el algoritmo controla los errores durante el calculo,

El metodo de biseccion encierra una raiz entre dos extremos con signos opuestos,
Newton usa una tangente para acercarse a la raiz, x nuevo = x - f(x) / f'(x),
Cada metodo requiere supuestos y un criterio de parada,
