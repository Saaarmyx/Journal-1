title: Mi prueba por induccion
---

Yo verifico n = 1, ambos lados valen 1, esa es mi base,

Ahora supongo que la suma hasta n es n(n + 1) / 2, a ambos lados sumo n + 1,

Queda n(n + 1) / 2 + n + 1, saco factor comun n + 1 y obtengo (n + 1)(n + 2) / 2,

Yo obtengo la misma formula para el siguiente entero, ya verifique base y paso inductivo,
