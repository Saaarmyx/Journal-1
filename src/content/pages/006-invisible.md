title: Uso basico de la terminal y git
---

Si no tienes idea de usar la terminal ni **git**, te voy a explicar brevemente

Con los siguientes comandos:

- `git -h` y `git --help`: Pides ayuda a **git** para saber que comandos usar

## linux y Mac

Para windows necesitamos una terminal basada en unix, no cmd ni powershell

- `ls`: Permite ver todos los directorios o carpetas y archivos del sistema

- `cd`: Permite movernos entre los directorios
  - `cd ..`: Permite ir hacia atras desde el directorio que estamos

- `pwd`: Nos muestra en el directorio que estamos

- `mkdir`: Nos permite crear una carpeta

- `touch`: Nos permite crear un fichero o archivo

- `clear`: Nos permite limpiar la consola
